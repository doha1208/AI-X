# 여성범죄주의구간 API 도입 사전 검토

검토일: 2026-11-02 KST. 대상: 공공데이터포털 15153436 / 재난안전데이터 공유플랫폼 DSSP-IF-00149.

## 판단

**현재는 도입 기준 통과를 선언할 수 없다.** 공간 자료로 활용할 기술적 가능성은 확인했으나, 경기도 전체 커버리지·등급 의미·분석 기준기간·가공 허용 범위가 확인되지 않았다. 공개 샘플과 현재 소스를 조사했으며, 프로그램 코드·설정·DB·경로 산출물은 변경하지 않았다. 이 문서만 추가했다.

| 검토 요소 | 확인 결과 | 판정 |
| --- | --- | --- |
| 경기도 커버리지 | 공개 샘플 100건은 모두 서울(시도코드 11). 기존 플랫폼 키로 대상 API 호출 시 접근거부(20). 경기도 전체 건수·시군별 분포를 확인하지 못함 | 보류 |

## 직접 확인한 데이터

공식 페이지의 공개 샘플 다운로드 기능과 API 명세를 읽었다. 전체 데이터 조회나 활용신청 제출은 하지 않았다. 기존 `backend/.env`의 `SAFETYDATA_API_KEY`는 동일 플랫폼의 기존 경찰 POI 수집에 사용하는 키다. 키 값을 출력하지 않고 대상 API에 1건만 요청했으며, HTTP 200과 별개로 응답 header에 `resultCode=20`, `resultMsg=SERVICE ACCESS DENIED ERROR`, `errorMsg=서비스 접근거부`가 반환됐다. HTTP 성공만으로 데이터 조회 성공을 판단하면 안 된다.

API 주소: `https://www.safetydata.go.kr/V2/api/DSSP-IF-00149`

명세의 요청변수는 `serviceKey`, `numOfRows`, `pageNo`, `returnType`이다. 지역 필터는 문서에 없으므로 지원 여부가 확인되기 전에는 전체 페이지를 수집한 뒤 지역을 분류하는 방식을 예상해야 한다. 활용 권한을 확보한 뒤 전체 페이지 누락·중복과 실제 전체 건수를 검증해야 한다.

샘플 다운로드는 첫 100건에 한정된다. CSV 첫 행은 영문 필드명, 다음 행은 한글 설명이므로 설명 행을 제외하고 집계했다.

| --- | --- |
| CSV 필드 | SN, TYPE_NM, TYPE_CD, GRD, STDG_CTPV_CD, STDG_SGG_CD, GEOM |
| 데이터 행 | 100 |
| 시도 | 서울 100, 경기 0 — 샘플 편향이며 경기 미제공의 증거가 아님 |
| 도형 종류 | MultiPolygon 97, Polygon 3 |

| 샘플 CSV SHA-256 | a964bc049b24ad341a040f2a3eee74a9604410ac0c6830c53f948ca94a7aa676 |

Shapely 2.1.2와 pyproj 3.7.2로 검사했다. EPSG:3857이라고 가정하고 EPSG:4326으로 변환한 경계는 경도 127.004465~127.109693, 위도 37.527284~37.647928이었다. 첫 좌표 `(14145030.2140781, 4518245.0682675)`는 경도 127.066968, 위도 37.565635로 변환된다. 이는 서울 코드와 지리적으로 부합하지만, 좌표계의 공식 확인이나 도로 정합성 검증을 대체하지 않는다.

100개 레코드 안에 10,609개 도형 조각이 있으므로 레코드 수를 도로 구간 수로 해석하면 안 된다. 전체 자료를 브라우저에 한꺼번에 그릴 때의 성능도 별도 확인해야 한다.

## 공간정보 도입 조건

- 경기도 시도코드 41 자료의 전체 레코드 수, 유형별 수, 실제 도형 조각 수, 시군별 분포를 집계한다. 단순 건수보다 서비스 대상 지역과 보행망을 얼마나 포함하는지 확인한다.
- 미제공 지역, 정상 수집됐지만 분석 대상 구역이 없는 지역, 수집 실패를 분리한다. 표시가 없다고 안전한 곳으로 판정하지 않는다.
- `STDG_SGG_CD`는 법정동 계열 시군구 코드다. 현재 `dong_code` 행정동 식별자와 직접 결합하지 않고 경계·도형을 이용한다. 광역 코드와 실제 도형 위치가 일치하는지도 검사한다.
- 제공기관에 원본 좌표계, 분석 공간 해상도, 도형 생성 기준과 위치 오차를 확인한다. 현재 OSM 보행망과 카카오 배경 지도에서 주요 지역·경계·하천·교량을 대조한다.
- 도형은 도로 식별자가 없는 면 자료다. 간선의 전체 LineString과 주의영역의 교차 길이를 계산한다. 간선 중점 하나, 도형 중심점, 최근접 도로 하나로 대신하면 길게 굽은 구간이나 평행 도로에서 오차가 생긴다.
- 길이·거리 검증은 적절한 미터 좌표계에서 수행한다. EPSG:3857은 표시용 좌표계로 쓰되 길이를 무보정 실거리로 해석하지 않는다. 버퍼는 위치 오차 근거가 있을 때만 도입하고 여러 거리에서 민감도를 비교한다.
- 전체 범죄와 개별 범죄 도형이 중첩될 수 있다. 전체 유형과 개별 유형을 동시에 합산해 같은 신호를 중복 반영하지 않는다.

## 등급과 시점

공식 설명은 20~24시 전체 5대범죄 발생현황의 밀도분석이다. 여성 대상 범죄만을 의미하는지, 전체 피해자 범죄를 여성 귀갓길 참고정보로 제공하는지까지는 이 설명과 샘플 필드만으로 확정할 수 없다. 이를 곧바로 성범죄 발생 확률이나 개인 위험 확률로 안내해서는 안 된다.

명세의 GRD 설명은 '등급'뿐이다. 높은 숫자가 더 위험한지, 동일 간격의 값인지, 전국 공통 기준인지 시군별 상대 등급인지, 11이 일반 등급인지 특수값인지 확인이 필요하다. 선형으로 0~100점에 변환하거나 기존 범죄율을 덮어쓰지 않는다.

공유플랫폼 명세에 표시된 갱신주기는 1일, 데이터 갱신일은 2026-03-09다. 공공데이터포털 등록·수정일은 2025-11-21이다. 어느 날짜도 범죄 분석 기준기간을 증명하지 않는다. API 출력에 분석 시작일·종료일 필드도 없다. 관련 WMS 문서의 2021~2024 요청 예시를 이 API의 분석기간으로 간주할 수 없다.

현재 프로그램은 KST 22:00~06:00을 야간으로 처리하고 낮·밤 그래프 두 개만 게시한다. 신규 요인은 20:00 이상 24:00 미만에만 유효하다고 분리해야 한다. 이렇게 하면 기본 낮/밤과 신규 요인 활성 여부 조합은 네 가지가 된다.

| KST | 기존 조명·도로·시설 시간대 | 신규 20~24시 요인 |
| --- | --- | --- |
| 06~20시 | 낮 | 비활성 |
| 20~22시 | 낮 | 활성 |
| 22~24시 | 밤 | 활성 |
| 00~06시 | 밤 | 비활성 |

기존 야간 시작을 20시로 바꾸면 조명·시설 가중치까지 바뀌므로 이 자료 추가와 별개인 정책 변경이 된다. 시간대별 그래프와 캐시 키, 자동/수동 시간 선택, 20·22·24·06시 경계를 함께 다뤄야 한다. 현재 `frontend/src/lib/preferences.ts:95`는 수동 낮/밤 선택을 각각 12시/23시의 고정 `at`으로 바꾼다. 신규 요인까지 이 값을 따르면 수동 야간에서 늘 20~24시 자료가 활성화되므로, 실제 출발시각과 조명 조건의 수동 선택을 구분할 정책이 필요하다. 실제 보행 중 시간대 경계를 넘는 경로는 출발시간 기준인지 구간 도착시간 기준인지도 명시해야 한다. 네 조합을 위해 전체 그래프를 네 개 상주시키면 메모리가 늘 수 있으므로, 기존 그래프 공유와 비용 배열 분리 가능성 및 실제 메모리 사용량도 검토한다.

1. 공공데이터포털 15153436: 무료, 이용허락범위 제한 없음, 개발 자동승인 / 운영 심의승인.

따라서 단순히 무료라는 이유로 재가공·경로 점수 반영을 허용된 것으로 판단할 수 없다. 반대로 모든 가공이 금지된다고 단정하지도 않는다. 제공기관에 **대상 API ID를 명시하여** 다음 이용 형태별 적용 조건을 확인해야 한다.

- 원본 등급과 출처를 보존한 지도 중첩 표시.
- 좌표계 변환, GeoJSON 변환, 표시용 단순화·영역 자르기, 서버 캐시와 재배포.
- 도로별 교차 길이 계산과 등급의 수치 변환, 경로 비용 반영.
- 상업 서비스에서의 제공 여부와 운영단계 승인·트래픽 조건.

자료 담당부서는 공유플랫폼 명세상 행정안전부 예방안전과 044-205-4922다. 이 검토에서 문의나 신청을 대신 제출하지 않았다.

## 권장 도입 순서와 효과 판단

### 1. 검증 관문 해소

대상 API 활용 권한 확보 → 경기도 전체 자료의 완전성·분포·도형 정합성 확인 → 등급 정의와 분석기간 확인 → 표시·가공·운영 이용조건 확인. 현재는 이 단계다. 커버리지의 충분성은 시군별 공간 분포와 실제 경로 교차 결과로 판단해야 하며, 전국 건수만으로 통과시킬 수 없다.

### 2. 지도 표시와 기존 경로 관찰

원본 등급·출처·분석기간·20~24시 한계를 함께 표시하고 현재 추천 알고리즘은 유지한다. 화면 범위나 경로 주변에 필요한 도형만 표시해 성능을 확인한다. '위험 확정 구간' 대신 과거 분석에 따른 '주의구간'으로 안내하고, 미수집·표시 없음 상태를 구별한다.

동일 출발·도착·시각·데이터 버전에서 기존 추천 대안과 Tmap 일반 경로를 함께 관찰한다. 고정된 도시·군 지역, 주의구간 유무, 짧고 긴 경로와 시간대별 표본을 사용한다. 추천 경로의 간선 점수와 Tmap 동 점수를 직접 비교하는 대신 양쪽 선형 경로에 같은 방식으로 다음 값을 계산한다.

- 주의영역과 겹치는 길이(m), 전체 길이에 대한 비율.
- 등급 정의가 확인된 뒤의 등급별 교차 길이와 고등급 구간 연속 길이.
- 미수집·미상 지역 통과 길이, 도형 매칭 오류와 위치 오차.
- 경로 거리·예상 시간과 지도 표시 지연·메모리 영향.

기존 추천 경로가 이미 주의구간을 대부분 피한다면 경로 재계산의 추가 효용은 작고, 지도 정보 제공만으로도 가치가 있을 수 있다.

### 3. 효과 확인 후 경로 계산 실험

새 요인을 사용한 후보와 기존 후보를 오프라인으로 비교한다. 노출 감소와 추가 거리·시간을 함께 보고, 단절·과도한 우회·요청 지연·미수집 지역으로의 편향이 생기지 않는지 확인한다. 합격 기준과 허용 우회 수준은 결과를 보기 전에 정하고 별도 평가 표본에서 검증한다.

새 요인으로 경로를 바꾼 뒤 동일 요인 점수가 좋아졌다는 사실만으로 실제 안전 개선을 주장하지 않는다. 별도 시점 범죄자료나 현장 확인·사용자 평가 등 독립 근거가 필요하다. 확인된 효과 범위에 따라 '주의구간 노출 감소'로 설명할 수 있다.

효과가 확인되면 배치 산출물에 단계적으로 반영하고 기존 산출물로 복구할 수 있게 한다. 미수집 값은 0위험으로 처리하지 않는다. 현재 자료만으로 최종 가중치나 고등급 기준을 정할 근거는 없다.
