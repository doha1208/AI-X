# 경기도 보행 시설 자료 확보 방안

2026년 11월 6일 기준 조사. 공개 CSV·SHP와 API 표본을 읽어 검증했다. 수집 설정과 운영 산출물은 이 조사에서 건드리지 않았다.

## 우선순위

경기도 599개 동을 담은 로컬 산출물 `20261105T235746338522Z-default-v3`에서 낮 201개 동과 밤 133개 동이 단일 지표 또는 부분자료 상태다. 낮에는 보안등이 평가에 들어가지 않으므로, 낮 회색을 줄이는 첫 작업은 생활방범 CCTV 보완이다. 부천 37개, 화성 29개, 광명 18개 동이 모두 회색으로 세 시가 낮 회색의 84개 동을 차지한다. 이 수치는 우선 조사 대상 수다. 자료를 추가한 뒤 실제 평가 전환 수는 인접 시·군과 보행로 범위까지 재검증해 산정한다.

| 순서 | 대상 | 첫 시도 | 대체 경로 |
| --- | --- | --- | --- |
| 1 | 부천·화성·광명 생활방범 CCTV | 지자체 설치대장·GIS와 경기데이터드림 점 단위 자료 | 행정안전부 조회 API와 제출 이력 대조, 공공데이터 제공 신청 |
| 2 | 김포·시흥·고양 등 보안등 | 관리기관의 설치점 GIS를 확보해 기존 목록과 대조 | 재난안전데이터 보안등 POI와 국토지리정보원 1:1,000 조명 레이어를 교차 검증 |
| 3 | 위 작업 후에도 평가에서 빠지는 경계 동 | 해당 보행로의 시설 반경과 겹치는 인접 시·군 원자료 수집 | 공식 주소 공간자료로 일치 후보를 좁히고 시설 담당 부서에서 확인 |

행정안전부 CCTV 명세에서 도시 필터는 `cond[OPN_ATMY_GRP_CD::EQ]`다. `/info`는 `serviceKey`, `pageNo`, `numOfRows`를 사용하며 `/history`에는 `cond[BASE_DATE::EQ]`를 추가한다. 먼저 부천 `3860000`, 광명 `3900000`, 화성 `5530000`에 대해 현재·이력의 집계와 설치목적을 비교한다. 개편 전후 도시·구 코드는 공식 기관 목록에서 확인해 각각 조회한다.

## CCTV 원본을 구하는 경로

- **부천시**는 2026년 7월 기준 생활방범 1,746개소와 카메라 6,713대를 공시했다. 공시의 개소 수는 시의 지점별 목록을 받았을 때 범위를 대조하는 기준이 된다. LOCALDATA의 다목적 장비는 설치대장과 지점별로 연결해 생활방범 기능을 확인한 것만 분류한다. [부천시 CCTV 운영 현황](https://www.bucheon.go.kr/site/homepage/menu/viewMenu?menuid=148006006011)
- **화성시**는 LOCALDATA의 기존 시 코드로 받은 파일이 헤더만 반환됐다. 화성시 데이터로의 별도 공개 내보내기 응답은 JSON으로 내려온다. 공개 내보내기 한도인 50,000행 중 생활방범은 49,436행이었다. 이 중 좌표가 화성 주변의 범위에 든 36,883행은 월별 중복을 제거하면 **고유 위경도 7,771쌍**이다. 이 좌표의 원본 기준일은 2019-12-16 또는 2021-10-19이고, 나머지 생활방범 12,553행은 유효한 직접 좌표가 없었다. 기존 시설의 위치 대조에 활용하고, 개편 이후 관할 구까지 포함한 최신 전수 설치대장을 별도로 확보한다. [화성시 데이터로 CCTV](https://data.hscity.go.kr/external/dataList/dataDtlView.do?dataCd=DAT0000037)
- **광명시**는 2023년 CCTV 공간자료의 SHP·SHX·PRJ·DBF를 공공데이터포털에 등록했다. [공식 ZIP](https://data.gm.go.kr/portal/data/file/downloadFileData.do?infId=TFMF3ETSUU1037BO4Z69121&infSeq=2&fileSeq=12865475)을 실제로 받아 도형과 속성을 읽었다. 개별 레이어는 417개 점을 담았고, 확인 가능한 설치일은 2013~2014년이다. `CTV_CDE` 코드의 공식 용도표와 최신 설치대장을 받아 대조하는 데 활용한다. [광명시 CCTV 공간정보](https://www.data.go.kr/data/15067254/fileData.do)
- **경기데이터드림**에는 CCTV 제공표준 데이터가 등록돼 있다. 직접 CSV URL은 이번 호출에서 HTML을 반환해 자료 행을 읽지 못했다. 공식 화면의 다운로드와 제공기관의 승인 API가 다음 확인 경로다. [경기데이터드림 CCTV](https://data.gg.go.kr/portal/data/service/selectServicePage.do?infId=VIPK0N53968Q7DV5TT2312643570&infSeq=3)

화성시 공개 다운로드의 브라우저 요청은 `POST /external/dataList/getExFileDataDownload.do`다. 데이터 식별자는 `DAT0000037`, 테이블은 `B_002_API_TO_PG_XML_GIS_POINT_055_GG_CCTV_P`이며 기준일 선택값은 `datePickerDate`다. 세 날짜로 호출했을 때 반환 바이트 수와 첫 행이 같아, 최신성은 파일의 `data_std_de`와 `std_ym`으로 대조한다. 공개 한도를 넘는 추출은 공식 페이지가 안내하는 담당 부서에 요청한다.

## 보안등 좌표를 확보하는 경로

보관된 공식 원본의 좌표 누락은 36,378행이다. 6개 시 모두 누락 행마다 도로명 또는 지번주소 문자열이 하나 이상 남아 있었다. 아래 행 수에는 주소가 반복되는 경우도 포함된다.

| 시 | 좌표 누락 | 도로명주소가 있는 누락 행 | 지번주소가 있는 누락 행 |
| --- | ---: | ---: | ---: |
| 고양 | 14,447 | 4,087 | 14,293 |
| 김포 | 11,504 | 0 | 11,504 |
| 시흥 | 9,298 | 189 | 9,109 |
| 안양 | 903 | 264 | 639 |
| 여주 | 225 | 0 | 225 |
| 광주 | 1 | 1 | 0 |

1. **지자체 설치대장·도로조명 GIS를 먼저 확보한다.** 관리기관과 시설 관리번호가 일치하는 측정 좌표를 우선 사용한다. 지역 전체 파일과 일부 사업·공원·특정 도로 파일을 구별한다. 이름이나 주소만 같은 행은 서로 다른 조명 기둥일 수 있으므로 자동으로 합치지 않는다.
2. **다른 국가 기관의 점 레이어로 대조한다.** 행정안전부 재난안전데이터공유플랫폼의 보안등·가로등 공개 CSV를 실제로 받았다. 두 파일 모두 실제 시설 표본 100행에 X/Y가 들어 있다. 보안등에는 점 도형도 확인됐다. 표본에는 경기도 코드 41이 없고 기준일 열도 없다. 전체 REST API는 별도 이용 신청 후 경기도 6개 시의 행과 기준일, 좌표계, 가공·저장 조건을 확인한다. 국토지리정보원 수치지형도 1:1,000 조명 레이어는 보안등과 가로등 구분을 명세에 두고 있다. 작은 도엽에서 실제 속성, 기준일, 수록 범위를 먼저 확인한다. 브이월드의 김포·시흥 V1.0 파일은 제한된 다운로드 시도에서 ZIP을 확인하지 못했다. [보안등 POI](https://www.safetydata.go.kr/disaster-data/view?dataSn=74) · [가로등 POI](https://www.safetydata.go.kr/disaster-data/view?dataSn=75) · [국토지리정보원 수치지형도](https://www.data.go.kr/data/15059719/fileData.do) · [수치지도 표준 속성](https://www.law.go.kr/LSW/flDownload.do?bylClsCd=200201&flSeq=145877779)
3. **공식 주소정보로 후보를 좁힌다.** 도로명과 지번을 정규화하고 공식 주소 공간자료 또는 행정안전부 주소검색·좌표 API의 식별자로 정확 일치시킨다. 건물·필지 대표점은 조명 기둥 설치점과 구별해 후보로 보관한다. 시설과 직접 연결되는 사물주소나 국가지점번호가 있으면 해당 원본의 기준점과 정밀도를 보존한다. [주소검색 API](https://www.data.go.kr/data/15057017/openapi.do) · [좌표 API](https://www.data.go.kr/data/15056663/openapi.do) · [사물주소 전자지도](https://www.data.go.kr/data/15096723/fileData.do) · [국가지점번호](https://business.juso.go.kr/jsu/jsuPremier)
4. **지도·검색 서비스는 검증 범위를 구분한다.** 생활안전지도 보안등은 WMS 표시용이며 공식 페이지의 XML 제공은 준비 중이다. WMS는 화면 표본 대조에 쓸 수 있다. 카카오 운영 답변과 브이월드 지오코더 명세에는 결과의 별도 DB 저장 제한이 있다. 시설 산출물의 좌표는 저장·재사용이 허용되는 원본에서 확보한다. [생활안전지도 보안등](https://www.safemap.go.kr/opna/data/dataViewRenew.do?objtId=220) · [카카오 운영 답변](https://devtalk.kakao.com/t/local-api-db/152489) · [브이월드 지오코더](https://www.data.go.kr/data/15101106/openapi.do)

경기도 도로대장의 가로등 데이터는 도로 구간의 시작·끝 좌표와 등기구 수량을 제공한다. 구간별 도로조명 확인에는 도움이 되고, 끝점 좌표를 개별 보안등 위치로 변환할 근거는 제공하지 않는다. [경기도 도로대장](https://www.data.go.kr/catalog/15123299/fileData.json)

## 수집부터 검증까지

1. `collect_route_public_sources.py`의 원본·수집 영수증·해시 보존을 재사용한다. 시·군, 공급자, 관리번호, 설치 목적, 원본 좌표계, 원본 기준일, 취득일, 이용 조건을 기록한다. CSV와 API는 행 수와 페이지를 대조한다. SHP는 원본 압축 파일과 PRJ·DBF를 보존하고, 좌표 변환·목적 분류·제외 내역을 남긴다.
2. 위치를 **측정 좌표**, **시설 식별자로 검증된 좌표**, **주소 기반 후보**, **미확인**으로 나눈다. 처음에는 지자체별 표본 30건과 중복·경계·좌표계 의심 건을 대조한다. 부분 목록은 확인된 시설 위치의 근거로 사용할 수 있다. 종합평가용 조사 범위는 원본의 관할과 수집 완결성을 검증한 뒤 선언한다.
3. 설치대장과 좌표의 기준일이 일치하는지 확인한다. 관리기관과 시설 ID로 먼저 중복을 제거하고, ID가 없는 경우 주소·좌표·용도 조합으로 대조한다. 같은 위치의 카메라 대수와 설치 지점 수를 구분한다. 철거, 교체, 다목적 장비의 용도는 관리기관 자료를 우선한다. 두 소스가 같은 전국 취합 원본을 공유하면 독립적으로 확인한 시설 수로 중복 집계하지 않는다.
4. 격리된 산출물로 낮·밤 599개 동을 다시 평가해 **회색에서 종합 평가로 전환된 동 수**를 시·군별로 비교한다. 확보한 행 수, 유효 좌표 수, 끝까지 미확인인 행, 경계 때문에 부족한 동도 함께 기록한다. 접경 동의 보행로 주변에 범위가 비면 필요한 인접 시·군의 원본을 추가하고 다시 평가한다.

## 보관본 적용 검사

- 보관 폴더의 경기도 CCTV 57,670행과 안전비상벨 32,601행은 현재 시설 평가의 공식 원본과 SHA-256이 각각 일치한다. 기존 파이프라인으로 별도 폴더에서 평가 입력을 다시 준비했으며, 96개 출처의 입력 명세 해시가 현재 산출물에 기록된 해시와 일치했다.
- 보관 과정에서 다시 내려받은 화성 응답은 앞서 조사한 표본과 행 구성이 달랐다. 보관된 JSON 50,000행은 2023~2024년 기준이며 위경도에 쓸 수 있는 값이 없었다. 도형을 직접 읽었을 때도 전부 `POINT (0 0)`이었다. 함께 저장한 CSV는 이 JSON을 변환한 파일이다.
- 광명 SHP의 용도 속성은 `CTV_CDE` 코드로 제공되며, 최신 설치대장과 공식 용도표가 있어야 생활방범 지점을 확인할 수 있다. 보안등·가로등 공개 표본에는 경기도 시설이 없었다. 세 자료의 종합 평가 반영은 검증 가능한 설치 위치와 평가 범위가 확보된 뒤 진행한다.
