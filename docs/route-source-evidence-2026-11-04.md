# 경로 평가 자료 확보·연결 결과

2026-11-04에 공식 원본을 실제 취득했다. 기존 좌표의 빈 출처 목록을 추정값으로 채우는 대신 새 원본·취득 영수증·해시·기준일·기관별 범위를 연결한다. 거주지 점수와 경로의 반경·동일 비중·최소 두 공통 요인 조건은 유지한다.

### 파주시 실제 자료

- CCTV 2,036행, 중복 제거 좌표 1,783곳, 원본 기준일 2025-12-23.
- 비상벨 1,725행, 고장 보고 23행을 제외한 중복 제거 좌표 1,529곳, 원본 기준일 2025-12-23.
- 보안등 6,204행, 중복 제거 좌표 6,167곳, 원본 기준일 2026-07-07.
- 취득일과 원본 기준일을 구분한다. 2026년에 받았다고 모든 자료의 기준일을 2026년으로 적지 않는다.
- 행정경계 밖에 표시된 좌표도 원본에 보존한다. 파주시 CCTV·비상벨 각 2행, 보안등 16행은 경계와의 불일치 수량으로 기록한다. 평가 가능 범위를 경계 밖으로 임의 확장하지 않는다.
- 지도 표시용 경계는 각 동을 약 20m 오차로 단순화해 동 사이에 작은 틈이 생길 수 있다. 실제 Tmap 파주 경로의 200m 평가 주변에서 이 틈 941m² 때문에 비상벨 전체가 범위 밖으로 제외되는 현상을 재현했다. 평가에는 기존 SGIS 가공 원본을 취득해 단순화 없이 시·군으로 합친 경계를 사용한다. 화면용 GeoJSON을 덮어쓰거나 범위를 임의 버퍼로 넓히지 않는다.

## 남는 결측과 처리

1. **CCTV의 목적·미제출을 구분한다.** 부천(3860000)은 원본 2,175행이 있으나 다목적 2,159·차량방범 16행으로, 생활방범 지점이라고 일괄 간주하지 않는다. 광명(3900000)은 기타·어린이보호·차량방범 277행이며, 화성(5530000)은 이번 공식 파일에 행 자체가 없다. 해당 시의 지점별 목적을 확인할 별도 지자체 자료로 보완할 대상이다. 세 지역을 모두 ‘CCTV 없음’이나 같은 미제출로 해석하지 않는다.
2. **보안등은 주소 기반 보완 대상이 남는다.** 고양 14,447행·안양 903행·시흥 9,298행·김포 11,504행·여주 225행·광주 1행의 좌표가 없다. 공식 주소와 기준일은 원본에 남겨 두었다. 기존 지오코딩 캐시에는 다수 주소의 결과가 있지만 첫 검색 결과만 저장하고 정확 일치 검증·취득 시각을 남기지 않았으므로 직접 측정 좌표로 승격하지 않는다. 주소를 정확히 대조하는 재지오코딩과 위치 정밀도 확인이 다음 수단이다. 기존 좌표는 부분 관측으로 보존하며 다른 지역의 보안등 지표는 함께 제외하지 않는다.
3. **고장으로 보고된 비상벨을 가점에 쓰지 않는다.** 공식 파일의 최종점검결과구분 N은 41행이다. 접근 지표에서는 제외하고 원본·제외 수량은 남긴다. Y도 과거 점검 결과이며 현재 정상 작동 보장은 아니다.
4. **상점 시간표를 현재 영업·유인 상태와 구분한다.** 공식 체인 검색에서 시작/종료 시각, 24시간·무인 표시를 실제 확보했다. 0000~0000인데 24시간 표시가 없는 경우 등 해석이 불충분한 443곳은 미상으로 둔다. 요일·휴무·유인 여부와 전체 상점의 조사 범위가 남아 있어 종합 open_store 요인과 ‘도움을 받을 시설이 없는 연속 구간’에는 아직 넣지 않는다. 확보한 시간표 좌표 수는 별도 상세 관측으로 연결한다.
5. **상점 식별자 손실을 예방한다.** 현재 과거 상점 JSON에는 좌표와 원본 ZIP 이름만 있어 점포 ID·이름·주소를 역으로 확정할 수 없다. 상가 ZIP 추출기는 앞으로 이 항목과 원본 해시도 보존한다. 기존 파일의 `소상공인시장진흥공단_상가(상권)정보_20260630.zip`은 복원 단서이며 실제 원본을 다시 확보하지 않은 상태에서 모든 점포의 영업시간을 연결했다고 주장하지 않는다.

## 평가의 의미

`verified_collection`은 공식 제공 목록을 정상 취득하고 선언한 기관 범위에서 좌표·기준일을 처리했다는 뜻이다. 현실의 모든 민간·공공 시설을 전수 조사했다는 뜻이 아니다. 원본 파일 해시와 좌표 파일 해시를 각각 검사하며, 손상된 자료로 이전 정상 manifest를 교체하지 않는다. 일반 경로와 추천 후보는 같은 요인을 사용한다. 상점 시간이 불충분해도 CCTV·비상벨 등 공통으로 확인한 다른 요인이 둘 이상이면 해당 요인으로 시설 접근성 점수를 계산한다. 모든 요인의 실제 안전 효과를 검증한 확률 점수가 아니다.

보안등은 정규화한 전체 행 목록 외에 API의 실제 원문 페이지도 각각 해시별로 보존하고 source 근거에 페이지 번호·URL·취득 시각·해시를 연결한다. 같은 날 다시 받아도 과거 원문은 남는다. totalCount, 페이지 번호, 행 수, 반복된 페이지 내용을 검사한다. 경계 원본도 별도 해시로 보존한다. 기관 목록에서 경계를 연결하지 못한 항목은 별도 진단으로 남긴다. 이번 목록의 경기도 본청(6410000)은 시·군별 경계가 없어 미연결로 기록했다.

## 실제 경로 검증

Tmap이 반환한 파주 보행 경로 1,566.7m에 같은 좌표를 일반·추천 후보로 각각 전달했다. 낮 74.89점(CCTV·비상벨), 밤 49.93점(CCTV·비상벨·보안등)이며 같은 시각·좌표의 두 후보는 정확히 같은 점수를 받았다. 주변 비상벨 32곳·CCTV 10곳이 관측된다. 영업시간 요인이 미확인이므로 종합 시설 공백은 null로 유지한다. 이 경로에서 보안등 0곳은 해당 공개 목록의 반경 내 관측 수이며 실제 도로가 어둡거나 모든 조명 시설이 없다는 뜻은 아니다.

최종 산출물 `20261104T105145790112Z`를 게시하고 API 8001을 재시작했다. `/health`는 산출물 사용 가능·평가 준비 완료·자동 빌더 실행 중을 반환했다. 실제 야간 경로 API의 추천은 55.75점(주변 비상벨36·CCTV11·보안등5 좌표), 일반 비교는49.93점이며 동일 comparison_group_id와 CCTV·비상벨·보안등 지표를 사용한다. 점수 차이는 서로 다른 실제 폴리라인의 관측 접근성 차이다. 대안은2개이며 상점 시간 요인만 미확인이다. 프런트 `/route` 응답200을 확인했다.

검증: 백엔드 전체297개 통과(pytest 반환0), 프런트 경로 표시6개 통과, ESLint와 Next webpack 운영 빌드 통과. 독립 읽기 전용 코드 검토 후 반복 페이지와 원문 보존 문제를 회귀 테스트로 수정했다.
