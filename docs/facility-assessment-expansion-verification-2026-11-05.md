# 시설 평가 확장 최종 검증 기록

승인된 1~7단계의 변경과 로컬 최종 검증을 완료했다. 구현 검증 시점에는 Git 변경과 운영 배포를 실행하지 않았다. 이후 사용자가 적용 순서대로 커밋을 요청하고 이번 요청의 스테이징·커밋 예외를 명시적으로 승인하여 아래 순서로 커밋을 정리했다. 푸시와 운영 배포는 실행하지 않았다.

1. 집 리포트의 밤 귀갓길 시설 평가 연결
2. 공통 시설 평가·정확한 경계 판정·현재 KST 날짜 처리
3. 물리 보행 색인·동별 집계·schema4 산출물
4. 주변 보행 평가·출처가 있는 거점·집 리포트 전환
5. 기존 폴리라인의 실시간 평가·공백/음성 안내
6. 거주지 시설 비교·지도·관심 동네 기준 분리
7. 출처/관리자 설명·구 계산 제거·실시간 평가 시각·최종 검증 기록

공통 파일은 단계별 내용으로 분리해 각 커밋의 색인 내용을 별도 검증 폴더로 내보내 검사했다. 1/2/4/5/6/7단계 타입 검사 및 관련 프런트 테스트와 2~7단계 관련 백엔드 테스트, 마지막 스모크 계약 테스트를 통과한 후 커밋했다. 5단계 내보낸 폴더의 실제 데이터 부재로 기존 비상벨 캐시 테스트 하나가 실패하여 제품 코드를 변경하지 않고 변경된 경로 응답 테스트와 새 실시간 API 테스트22개를 따로 검증했다. 원래 작업공간의 전체377개 통과 기록과 구분한다.

## 7단계 변경

- 데이터 출처·내 정보의 설명에서 지역 통계, 보행 시설 접근성, 실시간 공백 알림을 분리했다. 계산·시간대·정책 상세는 기본 접힘이다.
- 2026-11-04 시설 수집과 기존 거주지 통계의 기준일을 구분했다. 기관별 원자료 기준일, 공개 시간표의 일부 매장 범위, OSM의 보행망 한계를 명시한다. 공원·하천·유흥 원자료는 보존한다.
- 관리자 가중치는 지역 통계에만 적용한다. 시설 모델·정책·산출물 적용과 주변/동별 준비 상태는 조회만 제공한다.
- 구 spot 격자·지점 점수 계산과 생산 코드 연결을 제거했다. 기존 API 점수 필드는 deprecated·null 호환만 유지한다.
- 운영 스모크는 경로 없음·보행만 가능·시설 평가 가능을 분리하며 직선 경로와 구 점수로 통과시키지 않는다.

## 독립 검토와 수정

새 검토 에이전트가 설계·계획·현재 미커밋 전체 변경을 읽었다. Critical은 없었으며 아래 두 항목을 수정했다. 재검토 에이전트는 추가로 실행하지 않았다.

1. 근사 반경 버퍼와 정확한 표본 경계 거리의 차이로 짧은 절단 보행 구간이 공통 지표로 잘못 선택되어 예외가 발생했다. 지역/경로의 공통 지표 선택도 원본 보행 형상과 STRtree의 정확한 경계 거리로 바꿨다. 엄격한 미상 판정과 그룹 공통 지표는 유지했다. 면적·경로 재현 테스트 2건 실패 후 수정했으며 정상 여유 범위 2건도 통과했다.
2. 실시간 상세에서 실제 평가 시각/시간대를 확인할 수 없었다. 수동 미리보기와 현재 안내의 혼동을 막기 위해 중요 항목으로 판단했다. KST 시각·낮/밤·모델/정책/산출물과 준비 상태를 접힌 상세에 추가했고 UTC 자정 변환·준비 중 표시의 실패 테스트를 수정 후 통과시켰다.

보류한 경미한 지적과 판단을 미룬 항목은 없다.

## 구현 중 판단과 영향

- Git Bash 단계 도구 대신 PowerShell 로그·계획 체크박스로 진행을 기록했다. 자동 도구 메타데이터 대신 명시적 기록을 유지하며 커밋은 하지 않는다.
- 합성 소수 계산은 부동소수점 근사 비교로 검사한다. 실제 반환 정밀도·계산식과 기존 6개 경로 fixture의 완전 일치는 변경하지 않는다.
- 모든 연결 성분을 NetworkX로 중복 적재하면 16.32GB에 도달하여 물리 보행 색인은 XML 두 번 읽기로 만들었다. 원본 way 기준으로 형상을 보존하며 기존 경로 후보 그래프는 유지한다. 방식이 부적절하면 OSM 단순화 형상과 표본 분할이 달라질 수 있어 정/역방향·평행로·고립 도로 검증을 포함했다.
- 보행 색인은 motorway/motorway_link를 명시적으로 제외한다. 기존 후보 그래프 필터까지 바꾸지 않으며 자동차 전용 길의 혼입을 방지한다.
- 도움 거점의 편의점 분류는 명시된 매장 출처만 사용한다. 일반 상점 파일의 업종을 추정하지 않아 일부 편의점이 거점 목록에 나타나지 않을 수 있지만 혼합 식당·상점을 편의점으로 오인하지 않는다.
- 같은 물리 공백은 시간표 갱신만으로 음성 쿨다운을 초기화하지 않는다. 경로·산출물·시간대가 바뀌면 초기화한다. 빈번한 중복 음성을 억제하며 시간표 변경 시 공백 근거는 다시 선택한다.
- 시간대가 없는 구 관심 동네는 첫 조회에서 조용히 기준값을 설정한다. 과거와의 첫 차이는 알리지 않으며 잘못된 변화 경보를 피한다.
- 실시간 평가 시각 누락은 중요 항목으로 처리했다. 미수정 시 수동 밤 미리보기를 현재 낮 안내로 오해할 수 있어 시각/시간대 표시를 추가했다.

## 실행 검증

최종 백엔드 전체 `pytest -q`: **377개 통과**(기존 경고8개). 프런트 전체 Vitest: **157개 통과**. ESLint와 `next build --webpack`, 운영 스모크 계약 테스트4개 및 `git diff --check` 통과. 마지막 설명 문구 수정 후 관련4개 테스트와 빌드도 통과했다. 새 요청 중 산출물 교체 테스트는 live/spot 각각 이전 응답 전체가 이전 버전, 다음 요청 전체가 새 버전임을 확인한다.

자동 빌더 작업9는673.652초 후 schema4 **`20261105T064133564191Z-default-v3`**를 게시했다. 입력 지문은 `93bed9cd80508fa1957e19ce08422fef0e7bc73e0e2444a6a12b52db06f89b07`이다. 물리 선분537,086개·경계599/599개·요일/주야간 집계8,386개, 경계 누락/오류0개이며 경로·주변·동별 준비 상태가 모두true다. API의 현재 모델/정책 적용과 같은 산출물 버전을 확인했고 빌더는오류 없이idle로 돌아왔다.
