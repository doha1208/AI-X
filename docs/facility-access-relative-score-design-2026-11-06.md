# 동별 보행 시설 접근성 상대 평가 설계

## 배경과 범위

안심거주지 화면에서 `보행 시설 접근성`을 선택하면, 같은 지표로 평가한 동 사이에서 해당 동이 어디에 위치하는지 목록과 지도에 표시한다. 공개 자료로 계산한 시설 인접 비율은 동 상세에서 확인할 수 있게 한다.

현재 종합점수는 CCTV·비상벨 등 평가에 사용한 지표별로 시설 반경 안에 드는 보행로 길이 비율을 구하고, 그 비율들을 같은 비중으로 평균한 값이다. 화면은 이를 `시설 N점`으로 표시하고 40점과 70점에서 색을 나눈다. 접근 비율이 낮은 집단에서는 중간 수준인 동도 낮은 등급으로 표시될 수 있다.

로컬 산출물 `20261105T235746338522Z-default-v3`에서 2026년 11월 6일 금요일 슬롯을 확인했다. 산출물에는 경기도 599개 동의 요일·시간대별 집계가 들어 있다.

| 기본 비교 집단 | 동 수 | 원값 중앙값 | 반올림 표시값이 40 미만인 동 |
| --- | ---: | ---: | ---: |
| 낮 12시 · CCTV·비상벨 | 398 | 44.3% | 175 |
| 밤 23시 · CCTV·비상벨·보안등 | 249 | 39.6% | 124 |

적용 범위는 안심거주지 화면의 동별 목록·지도·선택 동 상세다. 같은 화면에서 주변 검색을 하면 전체 비교 집단에서 계산한 값을 그대로 보여준다. 지역 통계 지수, 동네 비교 화면의 공통 지표 접근 비율, 집 주변 리포트, 경로 평가와 실시간 안내는 각자의 계산 기준을 사용한다.

## 상대값 방식

| 방식 | 장단점 |
| --- | --- |
| **집단 내 백분위** | 순위에 맞춰 해석할 수 있고 극단값의 크기에 덜 민감하다. 실제 접근성 차이의 크기는 원값으로 확인해야 한다. |
| 최솟값·최댓값을 0~100으로 재조정 | 집단 내 거리 차이가 일부 남지만 극단값의 영향이 크다. 값이 비슷한 집단도 0과 100으로 벌어진다. |
| 상대 구간만 표시 | `상위·중간·하위`가 간단하지만 구간 안에서 각 동의 위치를 보기 어렵다. |

**제안은 동점에 중간 위치를 부여하는 백분위다.** 지도는 백분위 구간을 초록·노랑·빨강으로 표시하고, 목록과 상세는 백분위와 기존 순위를 제공한다.

### 비교 집단과 산식

- API가 선택한 `basis_id`에 속하고 `multi_factor` 종합점수가 유효한 동을 사용한다. 기존 비교 기준이 구분하는 지표 조합, KST 요일·대표 시각, 모델·정책·경계 기준을 그대로 적용한다. 한 요청에서 같은 산출물 스냅샷만 읽고 기본 집단 선택도 기존의 가장 큰 집단 규칙을 따른다.
- 비교 집단에 동마다 한 표를 준다. 각 동 안에서 지표를 집계할 때 쓰는 보행로 길이 가중치는 원값에 반영돼 있다. 지도 확대 범위·주변 검색 반경·선택한 동 수에 따라 비교 집단을 다시 만들지 않는다.
- 기존 공동 순위와 동일하게 원값을 정수로 반올림한 뒤 동점을 판정한다. `N`을 집단 전체 동 수, `L`을 표시 원값이 더 낮은 동 수, `E`를 자신을 포함한 동점 동 수라고 할 때 `백분위 = 100 × (L + E / 2) / N`이다. 예를 들어 100개 동 중 70개가 더 낮고 자신을 포함한 4개가 동점이면 네 동의 백분위는 모두 72.0이다. 동 코드로 공동 순위 내 표시 순서를 고정한다.
- 첫 정책은 **20개 동 이상이고 반올림 원값이 두 종류 이상인 집단**에 백분위를 제공한다. 20개 기준은 순위 한 칸이 차지하는 폭을 5백분위점 이하로 제한하기 위한 설계값이다. 집단이 작으면 `상대 비교 표본 부족`, 20개 이상이지만 표시 원값이 모두 같으면 `집단 내 점수 차이 없음`을 표시한다. 소규모 집단의 기존 순위는 전체 동 수와 함께 볼 수 있고, 모두 동점이면 화면에서 순위 강조를 생략한다.
- 검증된 원값 `0%`도 집단에 포함하고 상세에 표시한다. 단일 지표·부분자료·자료 미확인·보행로 없음은 각 상태를 보존하며 백분위 집단과 분모에서 제외한다. 다른 지표 집단 등 종합 자료가 있지만 상대 비교에서 제외된 동은 보라색으로 표시한다.

## 화면과 API

| 위치 | 표시 방식 |
| --- | --- |
| 목록 | `백분위 72.0`과 `동일 지표 100개 동 중 공동 27위`처럼 표시한다. 집단 밖의 동에는 `다른 지표 집단`을 표시한다. |
| 지도 툴팁 | `가동 (중간권)`처럼 동 이름과 구간 또는 짧은 자료 상태를 표시한다. |
| 지도 범례 | `집단 내 상대 위치`를 제목으로 쓰고, 백분위 60.0 이상인 상위권은 초록, 10.0 이상 60.0 미만인 중간권은 노랑, 10.0 미만인 하위권은 빨강으로 표시한다. 종합 자료가 있는 상대 비교 제외 지역은 보라색, 단일 지표·부분자료·미확인은 회색으로 표시한다. |
| 선택 동 상세 | 백분위와 비교 동 수·지표·대표 시각을 표시한다. 접힌 평가 상세에 `지표별 시설 인접 비율 평균 18%`처럼 원값을 제공하고, 각 지표의 인접 비율을 함께 표시한다. 상대값을 계산할 수 없으면 확인된 원값과 사유를 바로 보여준다. |

안내 문구는 “백분위는 같은 지표로 평가한 동네 사이에서의 위치예요. 실제 시설 인접 비율은 평가 상세에서 볼 수 있어요.”로 제안한다. 백분위가 같은 위치에 동점이 몰릴 수 있으므로 범례 구간이 정확히 일정한 수의 동을 포함한다고 설명하지 않는다.

- `zone_environment_service.py`의 `list_facility_zones`가 기존 그룹화와 순위 정렬을 재사용한다. 선택 집단의 반올림 점수별 빈도로 백분위를 계산한다. 백분위는 소수 첫째 자리로 반환하고 화면 색도 같은 반환값으로 정한다. 준비된 집계만 읽으므로 산출물 형식 변경이나 재생성은 필요 없다.
- `GET /safety/facility-zones`의 동 항목에 `relative_percentile: number | null`과 공동 순위 여부인 `rank_tied`를 추가한다. 응답에 `relative_method: "midrank-percentile-v1"`을, 선택 집단에는 `relative_status`를 추가한다. 상태는 `available`, `insufficient_group`, `no_variation`이며 선택 집단이 없으면 해당 메타데이터를 비운다. 기존 `assessment.score`, `rank`, `basis_id`, `artifact_version`을 보존한다. 구버전 응답에서는 같은 결과 집단의 전체 동과 유효한 순위가 확인되는 경우에만 프런트에서 백분위를 복원한다. 백분위를 제공할 수 없으면 원값과 자료 범례를 표시한다.
- `frontend/src/lib/api.ts`에서 응답 타입을 확장한다. 안심거주지 시설 모드의 목록·지도·선택 동 상세에서 같은 표시 규칙을 공유한다. `watchedZones.ts`는 표시용 값과 분리해 기존 `assessment.score`로 저장과 변경 알림을 계산한다. 다른 동의 점수나 집단 구성 변화로 백분위만 바뀌는 경우 시설이 개선·악화됐다는 알림을 만들지 않는다.

## 구현 순서와 검증

1. `zone_environment_service.py`와 `backend/app/schemas/safety.py`에 상대값을 추가한다. `test_zone_environment_service.py`에서 동점과 순위 일치, 원값 0, 집단 경계, 최소 표본, 전원 동점, 준비 중 응답, 기존 409 동작을 확인한다.
2. `frontend/src/app/page.tsx`, `frontend/src/components/SafetyMap.tsx`, `frontend/src/lib/zoneDisplay.ts`, `frontend/src/lib/watchedZones.ts`를 연결한다. `residence.test.tsx`, `zoneDisplay.test.ts`, `watchedZones.test.ts`에서 목록·지도·상세의 같은 값과 색, 주변 필터 적용 전후의 동일 백분위, 구버전 응답과 기존 관심 동네 데이터의 호환성을 확인한다.
3. 로컬 산출물로 주야간 집단별 대상 동 수, 원값 중앙값, 백분위 제공 동 수와 지도 색 분포를 확인한다. 화면에서 낮과 밤 및 지표 집단을 전환하고, 이전 집단의 백분위가 잠시라도 섞이지 않는지 확인한다. 기능을 적용할 때 `DEVELOPMENT.md`에 동별 표시 기준과 원값·관심 알림의 의미를 반영한다.
